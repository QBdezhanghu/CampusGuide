# CampusGuide

> 中文名待定 · 参赛作品原型

一个**校园事务 AI 路由助手**：用户说出想办的事，它返回一张可执行的"行动卡"——去哪办、带什么、多久办完、依据是什么。

现有校园入口（如各类助手站）解决的是"入口在哪儿"，前提是用户已经知道要找谁。本项目解决的是**用户不知道该找谁**的那一步。

## 预期形态

| 项 | 结论 |
|---|---|
| 交付 | 移动端优先 Web（PWA），可添加到主屏幕 |
| 内核 | 知识库 + 工具调用 + LLM 编排，与前端解耦 |
| 后端 | 极薄一层，仅用于保管 API Key |
| 首个切片 | 作业 / 教务（有 DDL，能独立跑通完整闭环） |

## 不是本项目要做的事

- ❌ 复刻任何现有校园服务产品，或在其名字上做衍生命名
- ❌ 模拟登录、抓取教务 / 一卡通 / 学习通等系统数据
- ❌ 替用户自动提交表单（AI 只负责起草，用户负责提交）
- ❌ 商业级完备度：目标是一个能演示完整闭环的原型
